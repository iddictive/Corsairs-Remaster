# Underwater scene medium

The subsequent [isolated Metal candidate probe](renderer-candidate-20261111/README.md) measures the current replacement component; it does not establish integrated gameplay acceptance.

The [current-source sea and seabed replays](current-scene-20261111/README.md) capture the lower-sky defect and candidate, both sea modes, wave classification, resource fingerprints and bounded timing; they remain offscreen diagnostic evidence.

The open-sea fixture sets the camera at (0, −20, −80), looking horizontally at (0, −20, 170). `open-before.png` shows the mirrored sky below the water surface; `open-sea.png` shows the same engine-linked scene with depth-based underwater scattering. These are offscreen diagnostic frames, not gameplay acceptance. `seabed-before.png` and `seabed.png` use the installed authored Cuba1 seabed model, viewed from below the surface; they establish that real ground geometry remains visible, without creating substitute terrain. Open sea has no seabed in this fixture. The screenshots do not prove all coastlines, camera transitions, weather, or combat effects.

The weather sky publishes camera depth against the real sea height only for the main render target. A single scene pass applies attenuation to actual scene depth before HUD rendering; rays without geometry use their direction and camera depth to prevent the mirrored lower sky. It makes no extra pass above water, and the state is reset after Present. The seabed is still owned and rendered by the island/model system. Existing work on sea surfaces and rendering is not replaced.

The sequential 1280×800 open-sea runs used 90 frames at a 16 ms simulation step, eight ships, dynamic sky off, and no nuclear bursts. CPU median over the last 60 frames was 8.487 → 8.401 ms. The median recorded GPU interval was 5.036 → 5.117 ms; these short runs are not a battle or worst-case performance guarantee. Raw CPU and renderer traces are retained here. An above-water pair with the medium enabled versus forcibly disabled retained the same composition; per-channel mean absolute frame difference was 0.090/255, not bit-identical due to scene timing.

For reproduction from the repository root, set `WAVE_EVIDENCE_INPUT` to `docs/evidence/nuclear-foam-20261105/footprint-antitile-20261105`, `WAVE_RESULT_DIR` to a new empty directory, and `FLEET_WAVE_MATRIX=1`; run `open-sea-replay.py` or `seabed-replay.py` using `codex-run-scratch`. The scripts compile isolated backend, sky, sea and driver objects against the existing prepared build libraries and use the installed resources; they do not launch the game UI or mutate the shared build. The sea snapshot and fixture are in the referenced evidence directory. The seabed replay loads the real `islands/Cuba1/Cuba1_seabed` model directly rather than the island entity, so it does not establish complete island lifecycle or lighting.

# Cluster impact offscreen investigation

## Authored 3D alternative: JangaFX Ground Explosion

### Experimental Metal integration and spray isolation

#### 30-impact batching experiment

The backend now admits up to 64 combined active and pending-fallback GPU records, enough for two simultaneous 30-impact salvos when no older records occupy the budget. Overflow is not evicted silently: `StormMetalClusterImpact` returns false to its caller for immediate legacy fallback. If a later GPU flush fails, its preexisting fallback queue is consumed by the next ordnance update; that failure path can therefore wait one tick and is not a proof of zero-delay fallback. GPU drawing uses one render encoder per batch, rather than one per impact; no impacts are merged or intentionally dropped. The current producer source separately clamps `ClusterCount` to 20–30 (default 24), with a 64-missile reservation limit; that producer was modified by another owner and was not edited for this experiment.

The shader now cools the flame channel sooner than the VDB density, plays the smoke channel more slowly with an end fade, uses small ballistic streaks instead of large round water/soil particles, and applies a short depth-checked spherical refraction using one pre-salvo scene copy per frame only when young impacts exist. The land tint is brown. This is an approximate screen-space refraction and a procedural particle substitute, not a simulated fluid splash. It adds one scene copy and transient full-resolution texture when active; actual native camera, material lighting and GPU cost remain unverified.

`salvo30-before/` and `salvo30-cooled/` use the same 640×360 two-box scene, positions spanning ±55 m with ±20 m lateral spread, 25 ms stagger, and 0/1/8/30 requested impacts. For Kalibr, the producer traces the root hull geometry vertically and places the tail above the traced surface when a hit is found; if no geometry hit is available, it keeps the former launch point. The missile-facing basis has an extra nonparallel fallback. Cluster separation uses late separation, terminal travel time derived from inherited speed, a shorter per-child delay, and its own smaller body geometry. A disposable mathematical probe at 9 km verified initial velocity and endpoint continuity for Kalibr/Kinzhal, cluster/nuclear; cluster child durations were 1.92 s and 0.29 s respectively for the sampled +110 m endpoint. This does not establish the perceived launch position, body shading, visible separation, impact quality, or real collision behavior in game.

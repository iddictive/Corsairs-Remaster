# Putin recut candidate

Isolated trial, not registered for delivery. `model-source.gm` is the rebuilt neck mesh; `atlas-source.png` and `musket-locator-source.json` are retained inputs. `prepare.py` regenerates the normal and musket GM and the DXT1 texture, then checks their pinned hashes. Run it without arguments to verify existing prepared files, or with `--write` to rewrite only this directory. It does not install or start the game.

The head derives from [Putin Bust by cgmodelsnet](https://sketchfab.com/3d-models/aa3241a2f12443c483eb1b6eabb1e7fe), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The identity reference is the [23 February 2024 Kremlin portrait](https://commons.wikimedia.org/wiki/File:Vladimir_Putin_portrait_(2024-02-23).png), CC BY 4.0. The body and musket locators derive from the user's game assets; the atlas includes generated edits.

The recut reduces the visible posterior protrusion in sampled offline renders. Head and bridge winding was corrected to match the stock body; the separately registered prior candidate has opposite head winding, and the original CPU renderer did not cull backfaces. On a 1e-6 position grid this package has four boundary edges and two nonmanifold edges, all matching the stock body's coordinates and incidence, and zero same-winding shared edges. The bridge still stretches in extreme poses. Full discrete `man` and `mushketer` frame scans measure bridge edges only and used the geometrically identical pre-winding version. A CPU diagnostic attaches the stock musket mesh to this package's musket locator; its sampled idle, shot and run views show the weapon in the hands. Interpolation, actual engine culling, the runtime weapon attachment, equipment transitions, performance and gameplay are not verified. `docs/evidence/putin-model-20261113/README.md` contains commands, renders and limitations. The integration owner must decide whether and how to replace the separately registered candidate; do not register both manifests for identical target paths.

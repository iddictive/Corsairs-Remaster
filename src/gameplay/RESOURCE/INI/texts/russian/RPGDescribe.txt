Strength
{
Сила помогает носить добычу и определяет начальный запас жизни. С ней быстрее учишься среднему и тяжёлому оружию, а также орудийному делу — сундуки сами себя не утащат.
}

Perception
{
Восприятие — глазомер и чуткий слух. Ускоряет обучение лёгкому оружию, меткости, навигации, починке и скрытности: сначала приметь опасность, потом хватай саблю.
}

Agility
{
Реакция задаёт запас энергии для драки. Помогает быстрее освоить лёгкое и среднее оружие, пистолеты и абордаж — не путай крюк со своими штанами.
}

Charisma
{
Лидерство помогает обзавестись офицерами и быстрее учиться авторитету, торговле и защите. Команда охотнее слушает капитана с крепким словом.
}

Intellect
{
Обучаемость ускоряет рост ранга и получение способностей. Помогает быстрее освоить авторитет, торговлю, орудия, навигацию и абордаж — голова нужна даже тому, кто рубит с плеча.
}

Endurance
{
Выносливость определяет прирост жизни с рангом и помогает носить добычу. С ней быстрее учишься тяжёлому оружию, починке и защите — морская шкура должна быть крепкой.
}

Luck
{
Удача помогает быстрее учиться пистолетам, везению, меткости и скрытности. Полезная спутница, только порох всё равно держи сухим.
}

FencingLight
{
Владение лёгкими клинками: рапирами и небольшим оружием. Скорость обучения зависит от реакции на 90%, от восприятия на 10% — шевели рукой, пока враг замахивается.
}
Fencing
{
Владение средним оружием, прежде всего саблями. Для скорости обучения важны сила на 60% и реакция на 40% — крепкий удар любит ловкую руку.
}
FencingHeavy
{
Владение тяжёлыми палашами, мечами и топорами. Скорость обучения зависит от силы на 90%, от выносливости на 10% — такую сталь салаге не доверишь.
}
Pistol
{
Владение пистолетами и мушкетами. Для скорости обучения реакция и удача равно важны: по 50% — навёл, выстрелил, не зевай с зарядом.
}
Fortune
{
Везение помогает в рискованных делах. Скорость обучения целиком зависит от удачи — Фортуна любит тех, кто до берега добрался.
}

Leadership
{
Авторитет помогает вести команду и добиваться её доверия. Скорость обучения зависит от лидерства на 90%, от обучаемости на 10% — капитанское слово должно весить больше бутылки.
}

Commerce
{
Торговля помогает выгоднее покупать и продавать. Для скорости обучения важны обучаемость на 80% и лидерство на 20% — добыча хороша, выручка ещё лучше.
}

Accuracy
{
Меткость помогает класть корабельные заряды ближе к цели. Скорость обучения зависит от восприятия на 80%, от удачи на 20% — не трать порох на испуг рыбы.
}

Cannons
{
Орудийное дело помогает быстрее заряжать корабельные пушки. Скорость обучения зависит от обучаемости на 60%, от силы на 40% — зарядил, подкатил, огонь!
}

Sailing
{
Навигация помогает управлять кораблём; скорость обучения зависит от восприятия на 20%, от обучаемости на 80%. Для классов 1–6 нужно соответственно 95, 80, 65, 40, 25, 1: нехватка навигации снижает все умения и характеристики на величину недостачи.
}

Repair
{
Починка определяет, как умело команда чинит корабль. Скорость обучения зависит от выносливости на 80%, от восприятия на 20% — меньше дыр, больше шансов довезти добычу.
}

Grappling
{
Абордаж помогает брать вражеские корабли в рукопашной схватке. Для скорости обучения важны реакция на 70% и обучаемость на 30% — крючья на борт, молодцов вперёд!
}

Defence
{
Защита уменьшает потери корабля и команды в морском бою. Скорость обучения поровну зависит от выносливости и лидерства: по 50% — береги борт и своих людей.
}

Sneak
{
Скрытность помогает обманывать вражеские патрули и выдавать себя за своего. Скорость обучения поровну зависит от удачи и восприятия: по 50% — тише прошёл, целее вышел.
}

Loyality
{
Лояльность офицера зависит от твоих поступков. Честному негодяй не по нраву, мошеннику — слишком честный капитан; рассоритесь, и офицер уйдёт.
}

Ship_abilities
{
Свободные очки корабельных способностей. Потрать их на навыки, с которыми экипаж лучше управляется с кораблём.
}

Personal_abilities
{
Свободные очки личных способностей. Выбери, какой новый приём освоит капитан.
}

Rank
{
Ранг растёт вместе с опытом умений. Новый ранг прибавляет жизнь; в пути встречаются более сильные противники и новые предметы — добыча растёт вместе с опасностью.
}
Life
{
Жизнь — запас, который отнимают раны. С каждым рангом максимум растёт в зависимости от выносливости; обнулился — к рыбам.
}
Health
{
Здоровье — общее состояние капитана. Частые ранения портят его и ослабляют личные умения; передышка без серьёзных ран помогает восстановиться.
}
Energy
{
Энергия расходуется на удары в рукопашной и восстанавливается с передышкой. Максимум зависит от реакции — выдохся, не лезь под саблю.
}
Money
{
Монеты на наём, жалованье и покупки. Названий у них много, а звенят капитану одинаково приятно.
}
Reputation
{
Репутацию создают твои поступки: она влияет на отношение людей. Слава со временем стихает; дурные дела забываются медленнее добрых.
}
weight
{
Максимальный вес добычи, который можешь нести без перегруза. Зависит от силы и выносливости — хватит жадничать, ноги ещё нужны.
}
Title
{
Звание показывает заслуги перед державой, которой служишь. Хорошая служба тоже приносит добычу.
}
NextExp
{
Показаны накопленный опыт и порог следующего повышения для выбранного умения, ранга или способности. Умения растут от дела; их рост даёт опыт ранга и личных либо корабельных способностей.
}

TABLE_PERKS {Способности героя}

TABLE_PERKS_desc
{
Распределение способностей возможно, если есть очки в личных или корабельных умениях.

Nation_hint
{
Нация героя - это нация, выбранная в начале игры, или нация выданного в данный момент патента (герой на службе). Её видно на форме "Персонаж". На форме же "Нации" виден текущий флаг на корабле героя, который можно менять только в море для того, чтобы скрыть свою истинную суть. Но врага державы могут распознать как корабли в море, так и стражники в порту. Скрытность героя влияет на успех обмана. Если же у героя есть награда за голову от своей основной нации, то он считается врагом даже ей.
Распознавание врага происходит с учетом отношений самих стран и наград за голову от их имени.
Быстрый переход в городах-врагах герою не работает.
}

Partition_hint
{
Расчёты с командой производятся не позднее 1-го числа каждого месяца и включают в себя следующие выплаты:

Ежемесячное содержание - это совокупные затраты на жалование офицерам и матросам, выплаты по ранениям и увечьям и поддержание корабельного хозяйства в надлежащем порядке.

Доля добычи - это делёж захваченных ценностей и выплата долей членам команды.
Дележу подлежат захваченные корабли и товары. По обычаям Берегового братства доли погибших офицеров и матросов достаются их товарищам и родственникам.
Распределение долей среди членов команды:
- матрос - 1 доля
- офицер - 10 долей
- компаньон - 30 долей
- капитан - 200-650 долей
Доля капитана (игрока) зависит от уровня сложности игры (Матрос - 650, Невозможный - 200).
Помимо этого капитан, как владелец кораблей своей эскадры, получает дополнительно за каждый корабль 20-120 долей (в зависимости от класса судна). При этом все расходы, связанные с содержанием и возможной гибелью кораблей, капитан принимает на себя.

Задержка выплаты долей за текущий месяц ропота и недовольства в команде не вызывает до конца месяца. При этом досрочная выплата повышает мораль команды.
Задержка выплаты долей и содержания за истекший месяц влечет к существенному снижению морального духа команды и лояльности офицеров и компаньонов.
}

SPECIAL_desc
{
P - Сила. Влияет на переносимый вес и количество очков жизни, определяющая характеристика для умений - тяжёлые и среднее оружие, орудийные навыки.
I - Восприятие. Особенно сильно влияет на умения меткость, скрытность.
R - Реакция. Необходима для таких умений как лёгкое и среднее оружие, пистолеты, абордаж. Влияет на количество максимальной энергии.
A - Лидерство. Необходимый атрибут для таких умений как авторитет и коммерция. Влияет на количество присоединяющихся офицеров.
T - Обучаемость. Влияет на коммерцию, орудия, навигацию и, главное, на скорость роста ранга героя и получения им новых способностей.
E - Выносливость. Ремонт и защита сильнее всего зависят от этой характеристики, так же как прирост очков жизни и переносимый вес.
S - Удача. Влияет на умения пистолеты, везение, скрытность.
}
